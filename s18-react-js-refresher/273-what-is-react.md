# Lecture 273. Module Intro

**_What is React?_**

1. JS library to build User Interfaces which is what the user's see on the screen.
2. Runs in the browser not on a server.
3. Does not communicate with DB's.
4. To build highly reactive modern user interfaces by following a **_declarative_** approach.
   The dev's define the result and maybe different states of the result and under which state we want to render what and want to show what on the screen instead of the steps that lead to the result as that would be an imperative approach (a different programming style) which is the style of vanilla JS programming. We use declarative programming style as this is less error prone and takes a lot of effort and work away from our business logic and from building nice UI's.

   Therefore in React.js we focus on the result and by using Components which is a concept of UI building blocks which we define and we compose our UI from these Components. Every Component can define what it should render under which circumstance and React will then wire-up everthing behind the scenes and implement all these steps for us.

   ## Summary

   1. JS library for building UI's.
   2. Declarative Approach: we define the result, not the steps that lead to the results (and React will implement all the steps for us).
   3. We define Components and build our UI with them.
